# OOP-Bank-System
A Console-Based Bank Management System Built With C++, Demonstrating OOP, Class Organization, File Handling.
As a practical project for learning Object-Oriented Programming (OOP).

## About the Project

This project simulates basic banking operations through a console interface. It focuses on organizing application logic into classes and separating user interaction from business logic.

## Features

- Client management: add, find, update, and delete client records.
- User management and permission-based access control.
- Banking transactions, including deposits and withdrawals.
- Display client records and account balances.
- File handling for storing and retrieving application data.
- Organized classes for user interface and business logic.

## Technologies

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Visual Studio

## Project Structure

The project separates user-interface responsibilities from business logic using dedicated classes.

## How to Run

1. Clone or download this repository.
2. Open the solution file (`.sln`) in Visual Studio.
3. Build the solution.
4. Run the application.

## Learning Goals

This project helped me practice class design, constructors, encapsulation, static and non-static members, file handling, and relationships between classes.
